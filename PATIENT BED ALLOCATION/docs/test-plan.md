## Test Environment

- Python 3.14
- No external test runner required (unittest is in standard library)
- Data generated by `data/generate_data.py` must exist before running tests
- Tests import `app/validator.py` and `app/metrics.py` directly

## How to Run

```bash
python tests/test_all.py
```

Or with pytest (if installed):
```bash
python -m pytest tests/ -v
```
